# garmin-local
A self-hosted Garmin Connect alternative. Sync via Garmin account or direct device connection — data stays local. Written in Python

***Note: This software has been tested with Garmin vivosmart 5 on Linux***

## Features

- Download data from Garmin Connect account
- Download directly from Garmin Device 
- Visualize your data in Graphs
- Create an Overview (Weeks/Months)
- Export data as spreadsheet (.ods)
- Create artistic impressions of data as images
